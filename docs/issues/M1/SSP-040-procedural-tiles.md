# SSP-040: Generate placeholder ground tiles and the 47-tile kerb blob set with tiles.py

**Milestone:** [M1 Drivable Bessie](../README.md#m1) · **Type:** asset · **Size:** L · **Areas:** assets, tooling, test · **Vertical slice**

## Summary

Add the forge `procedural` technique and seeded `tools/forge/forge/procedural/tiles.py` generators for placeholder-quality asphalt, pavement slabs, the 47-tile kerb blob set, lane markings and grass, under final asset IDs packed into the `world` atlas. AI-generated ground tiles are banned: only code guarantees seams.

## Context

Generators (ASSET_PIPELINE §6.4):
- Pure `f(params, numpy.random.Generator(PCG64(seed)), cell, variant)` returning a uint8 (h, w) array of Kerbside-32 indices, never RGB. No `random`, no `time`, no unordered set iteration.
- Variant k draws after variants 0..k−1, so new variants are appended and never reorder existing ones.
- Params live in `assets-src/procedural/tiles/*.json`. Manifest example: `tile.asphalt`, cell [32, 32], states ['v'], dirs '-', frames {v: 6}, atlas world, generator `tiles.asphalt`, seed 1031. (ART_BIBLE §9.1 says asphalt has 4 variants; the manifest example says 6. Use 6 and note the discrepancy in the PR so the lead can fix one doc.)

Frame states (ART_BIBLE §14.4): `tile.*` frames use state `v` (variant n) or, for the kerb set, `blob` with n = autotile index 0–46 (*proposed*), dir `-`. So kerb frames are `tile.kerb:blob:-:0` … `tile.kerb:blob:-:46`, matching the compiler's autotile index.

Looks (ART_BIBLE §9.1; placeholder quality is fine, palette indices must be right):
- Asphalt: 02 base, 03/01 speckle ≤ 8% of pixels, clumps no larger than 2×1
- Pavement slabs: 05 with 04 joints on a ~10 px grid, random 06/04 slab tints
- Kerbs: 06 top, 07 NW lip, 04 SE lip, 01 gutter line, as a 47-tile blob generated by rule from the shared mask table in `assets-src/procedural/tiles/kerb_blob.json` (committed by SSP-034; never hand-edit the 47 tiles)
- Lane markings: 07 centre dashes, 2 × 32 px, 32 px gaps (*proposed*), worn to 06
- Grass: 22 base, 23 tufts, 21 shade
Calmness rule: ground has the lowest contrast in the game, with speckle within one ramp step of the base.

Seam rule: for `wrap: true` tiles, the wrap-edge difference must not exceed the interior difference (pytest, plus the forge lint Seams check if lint supports it yet).

IDs: only `tile.asphalt` is named in the docs. Choose and record the other tile asset IDs in the manifest, sorted by id (e.g. `tile.pavement`, `tile.kerb`, `tile.lane_marking`, `tile.grass`). They are final from then on (CLAUDE.md §5.4), so list them in the PR. OPEN: ENTITY_CATALOG lists no `tile.*` IDs and CLAUDE.md §5.4 says new IDs update entities.json/the catalog/the manifest together; ask the lead whether tile IDs need a catalog entry (proposal: manifest only, since tiles are not entities).

Puddle Lane also uses `;` setts, `+` apron, `z` zebra (07 bars 8 px wide on 02), `=` speed bump, `p` parking bays, `$` depot bay markings and double yellows (15 with 14 shade). Speed bumps use the canonical `haz.speed_bump` ID (ENTITY_CATALOG §10: 'rendered as a ground tile variant', atlas world, procedural; ART_BIBLE §8.7: a tile-wide band of 03 with 07 or 15 chevrons). Give each other feature a minimal placeholder variant, or document a fallback mapping to an existing tile, following the markings decision recorded by SSP-034, so no cell renders missing.

End steps (CLAUDE.md §3 rule 8, ROADMAP §1.1): build, `npm run assets:lint`, `npm run assets:sheets`, then Read `build/sheets/world.png` and the 3×3 tiled preview for every wrap tile (ASSET_PIPELINE §10.8; if the M0 minimal sheets lack the preview, add it). Also review in the asset zoo (`?test=1&scene=zoo`) if ZooScene exists yet.

## Scope

- `procedural` technique dispatch in forge build.py (by `generator`)
- tools/forge/forge/procedural/tiles.py: asphalt, pavement, kerb_blob (47 from the shared mask table), lane markings, grass, plus minimal placeholders or fallbacks for the other Puddle Lane ground features and haz.speed_bump
- assets-src/procedural/tiles/*.json params and manifest entries under final IDs
- pytest: determinism (same bytes twice), seam rule for wrap tiles, kerb blob produces exactly 47 frames matching the mask table, variant-append stability
- 3×3 tiled preview in forge sheets if missing
- Generated outputs committed (world atlas, FRAME entries, hashes)

## Out of scope

- Grime overlay patterns and stains (M2)
- Roof surfaces and facades: SSP-041

- [ ] Every wrap tile passes the seam test in pytest
- [ ] The kerb blob produces exactly 47 frames `tile.kerb:blob:-:0..46` whose edge/corner treatment matches the shared mask table (pytest checks the lip pixels per mask)
- [ ] forge lint passes (palette: no off-palette or semi-transparent pixels)
- [ ] The world contact sheet and wrap-tile 3×3 previews were opened with Read, and the PR notes what was checked
- [ ] The chosen tile IDs (and haz.speed_bump) are listed in the PR and in the sorted manifest
