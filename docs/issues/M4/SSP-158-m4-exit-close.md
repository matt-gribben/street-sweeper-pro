# SSP-158: M4 exit: no-placeholder test, full review pass and Close M4 PR

**Milestone:** [M4 Art Pass 1](../README.md#m4) · **Type:** release · **Size:** M · **Areas:** test, assets, docs, release · **Vertical slice**

## Summary

Prove every M4 exit criterion with evidence. Add `noPlaceholders.test.ts`, run the full review pass on all five contact sheets and the zoo, confirm goldens and CI, close the ART_BIBLE open items M4 owns, re-score the risk register, and open the `Close M4: Art Pass 1` PR for the lead's approval.

## Context

Canonical exit (ROADMAP M4): forge complete (ingest, build, lint, sheets, verify); real assets for every class used by Mon-Tue; fonts, UI and portraits in place; `assets:lint` + `assets:verify` in CI; contact sheets reviewed and noted in PRs; zoo golden. Measurable checks: forge pytest covers each command and `npm run assets` twice gives zero diff; verify runs in the ubuntu CI job; lint has zero warnings including 're-render needed'. `tests/unit/noPlaceholders.test.ts`: every asset referenced by `puddle_lane` and `high_street` has no `"placeholder": true` in the manifest. Derive the referenced set from the compiled levels (map legend, `level.json` spawn/placement tables) and `entities.json` district membership, rather than a hand list. Every `assets-src/ai/<id>/` has prompt.md, meta.json and golden.png with a matching golden_sha256. Each asset-batch PR links its sheet review notes and a zoo screenshot. The `zoo` and `hud_specimen` goldens pass at threshold 0. Also close out the ART_BIBLE §17 items M4 owns (swap slots, ramp lint 00, atlas trimming/padding, font metrics, animation timings, VFX IDs/HUD details). Check ADR 0002 revisit trigger 3 (human grid authoring > 2 working days per type) against the hours recorded in the character PRs, and re-score risks R-01 (art consistency), R-03 (image-gen drift) and R-12 (tool updates). Process: the milestone closes with a PR titled `Close M4: Art Pass 1` that ticks each criterion with links to evidence. Git tag `m4` follows only after the project lead approves (Claude proposes, the lead approves). A 1080p (4x) Puddle Lane capture is a useful preview for VS-10.
